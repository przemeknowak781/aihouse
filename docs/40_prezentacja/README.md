# Prezentacja projektu „Dom LAMELA”

Talia 16 slajdów (1920×1080) opublikowana jako prywatny artefakt typu Slides:
https://claude.ai/artifact/TexRXPDTXrH99W7nd24UVB — do pobrania jako .pptx / PDF (import do Prezentacji Google:
Plik → Importuj slajdy).

- `project/deck.json` — kolejność slajdów, sekcje, kroje pisma;
- `project/slides/*.html` — slajdy (HTML w podzbiorze typu Slides) z notatkami prelegenta w `<aside>`;
- `generuj_slajdy.py` — generator slajdów 2–16 (okładka pisana ręcznie).

Obrazy slajdów są zasobami artefaktu (`/_blob/<id>`), wykonanymi z plików repozytorium: renderów `www/`, rzutów
`docs/20_koncepcja/final/`, plansz `raporty/`, detali i arkuszy `projekt/`.

Liczby na slajdach: stan roboczy z 25.09.2026 (model przed zamrożeniem). Źródła: `docs/20_koncepcja/final/bilans.md`
i `lamela.wskazniki` (PU, zabudowa, PBC, wysokość), `projekt/08_obliczenia/fizyka_energia_runda2/` (EP, Φ_HL,
ciągłość warstw), `projekt/08_obliczenia/mostki/` (mostki), `projekt/04_PT_konstrukcja/rysunki/kontrola_zbrojenia.md`,
`docs/30_arkusze/zastosowanie_AR.md` (arkusze AR), `docs/20_koncepcja/koncepcja.md` (wierność szkicowi, program).
Po zamrożeniu modelu wartości na slajdach „parametry”, „rzuty” i „dokumentacja” należy zaktualizować.
